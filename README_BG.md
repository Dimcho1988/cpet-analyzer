# CPET Functional Diagnostics Lab — Streamlit прототип

Това е работещ прототип за лаборатория по функционална диагностика. Приложението приема CPET Excel/CSV файл, разпознава COSMED-подобна структура, изчислява газообменни прагове, FatMax, енергиен разход, икономичност, лактатни прагове и позволява експертна корекция.

## Стартиране

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

След стартиране качете CPET файла през страничния панел.

## Основни модули

1. **QC & пикови показатели** — VO₂peak, HRpeak, RERpeak, VEmax, FatOx max, икономичност и автоматични QC бележки.
2. **Прагове + експерт** — метод-специфични кандидати за VT1, VT2/RCP и FatMax; отделен consensus; плъзгачи за експертно потвърждение.
3. **Графики** — VO₂/VCO₂, V-slope, VE/VO₂, VE/VCO₂, PETO₂/PETCO₂, Fat/CHO oxidation, kcal/kg/km.
4. **Лактат** — качване или ръчно въвеждане; LT1 по първо трайно покачване; LT2 по Dmax и сегментирана регресия.
5. **Референции** — качване на собствена спортно-специфична база с перцентили.
6. **Доклад** — автоматичен редактируем проект на доклад и HTML export.
7. **Данни/експорт** — CSV/JSON export на данни, прагове и резултати.

## Прагове, които се изчисляват

- **VT1 по газообмен**: V-slope + VE/VO₂ + PETO₂/PETCO₂.
- **LT1 по лактат**: първо трайно покачване над базата.
- **FatMax**: от VO₂/VCO₂ чрез стоихиометрични уравнения; дава точка и диапазон, не само една стойност.
- **LT2 по лактат**: Dmax + сегментирана регресия.
- **VT2/RCP**: VE/VCO₂ nadir/rise + PETCO₂ peak/drop + VE/VCO₂ slope + RER support.
- **Финален тренировъчен праг**: ръчна експертна корекция/консенсус между LT2, VT2/RCP и полеви тест.
- **Икономичност**: kcal/kg/km от Weir-подобен подход: kcal/min = 3.941·VO₂ + 1.106·VCO₂, където VO₂ и VCO₂ са в L/min.

## Важна бележка

Това приложение е инструмент за стандартизация и подпомагане на експертната оценка. То не трябва да замества професионалното решение на физиолог/лекар/спортен учен, особено когато отделните критерии дават разнопосочни прагове.

## Референтни стойности

`reference_values_template.csv` съдържа структурата за собствена база:

```csv
sport,sex,age_min,age_max,level,metric,unit,higher_is_better,p10,p25,p50,p75,p90,source,note
```

Примерни имена на метрики, които приложението може да сравнява:

- `VO2peak_mL_kg_min`
- `HRpeak_bpm`
- `RERpeak`
- `FatOx_max_g_min`
- `best_economy_kcal_kg_km`
- `VT1_HR_bpm`
- `VT1_VO2kg`
- `VT1_speed_kmh`
- `RCP_HR_bpm`
- `RCP_VO2kg`
- `RCP_speed_kmh`
- `FatMax_g_min`

За показатели, при които по-ниската стойност е по-добра, например `best_economy_kcal_kg_km`, задайте `higher_is_better` = `false`.
